First, download the files into the directory you keep all your python file.

Second, open up the "Main.py" file on Pycharm or your preferef IDE and run the program, this will also create a csv file so there is no need to create one befoe hand.

Third, open up the "Performance graph.py" run the program and that will create a graph of the data from the csv file

Forth. the "Dashboard.py" is similar to bothe the "main.py" and "performance graph.py" except it doesn't store any of the data just displays in the terminal.
